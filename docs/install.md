# 安装与使用

prompt-hub 是一个提示词资产的桌面仪表盘：用一个全局快捷键唤起全屏窗口，找到你要的话术，复制走人。所有数据只存在你自己的机器上。

---

## 系统要求

macOS。Apple Silicon 与 Intel 各有独立安装包，按你的机器选：

| 机器 | 下载 |
|---|---|
| Apple Silicon（M 系列） | `prompt-hub_<版本>_aarch64-apple-darwin.dmg` |
| Intel | `prompt-hub_<版本>_x86_64-apple-darwin.dmg` |

不确定的话，点左上角 → 关于本机，看「芯片」一栏。

---

## 安装

1. 下载对应的 `.dmg` 并双击打开
2. 把 `prompt-hub` 拖进 `Applications`
3. 从启动台或应用程序文件夹打开

安装包经过 Apple 开发者签名与公证，正常双击即可打开，不需要右键「打开」或改任何安全设置。

---

## 唤起

装好后按 **⌥Space（Option + 空格）** 唤起主窗口，再按一次收起。这个快捷键在任何应用里都生效——这是它的主要用法：不用切到它，随手叫出来，拿了就走。

如果按下去没反应，多半是被别的软件占了同一个组合键（Alfred、Raycast、输入法切换等常见）。到那个软件里改掉它的绑定即可。

---

## 快捷键

| 按键 | 作用 |
|---|---|
| `⌥Space` | 唤起 / 收起主窗口（全局） |
| `⌘K` | 搜索 Macro / Phrase / 对齐话术 |
| `⌘1` – `⌘8` | 切换到第 N 个相位 |
| `⏎` | 复制选中项 |
| `⌘,` | 打开设置 |

---

## 调用态与整理态

右上角有个「调用 / 整理」开关，这是理解这个工具的关键：

- **调用态**是日常使用状态。点一张话术卡 = 直接复制走。卡片只显示标题，正文不上屏——名字就是把手。
- **整理态**是维护状态。点整卡 = 展开预览内容，复制变成一个显式的动作。增删改都在这一侧做。

这样分开是为了让「取用」和「编辑」不会互相误触。

---

## 更新

更新检查**默认关闭**。首次启动会问你一次要不要开启，你说了算：

- 关着的时候，应用**零出站**，不会向任何服务器发一个字节
- 开启后，每次启动检查一次。发现新版本只会提示，下载和安装都要你点确认，不会静默装
- 随时可以在 设置 → 关闭

开启后的出站请求只包含当前版本号和你的芯片架构，不携带任何话术内容或使用数据。

## 你的数据在哪

一个 SQLite 文件，在你自己的机器上：

```
~/Library/Application Support/dev.prompt-hub/prompt-hub.db
```

同目录下的 `backups/` 是**安全快照**：只在你执行导入、或应用升级需要改数据库结构时各拍一份，保留最近 5 份。**它不是定时备份**——日常数据没有自动副本，重要内容请用下面的导出功能自己留底。

**数据不会上传到任何地方。** 这是这个工具的设计前提，不是可配置项——话术里往往带着工作内容和个人表达习惯，那属于你。

想搬到另一台机器，或者想留个副本：设置 → 数据 → 导出，会生成一个完整的 JSON。导入是**整库替换**，会覆盖现有全部数据，操作前会让你确认。

## 常见问题

**⌥Space 没反应？**
被其他软件占用了。也可能是应用没在运行——看一眼 Dock 里有没有它的图标，没有就从应用程序文件夹打开一次。

**窗口消失了？**
复制之后窗口会自动隐藏，这是有意的：拿到东西就该回到你原来在做的事。整理态下不会自动隐藏。

**怎么卸载？**
把 `/Applications/prompt-hub.app` 拖进废纸篓。数据目录（上面那个路径）需要手动删，留着的话重装后数据还在。

**支持 Windows / Linux 吗？**
暂不支持。
