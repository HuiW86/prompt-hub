# 技能索引文件

`skill-index.json` 是「技能」工作区的导入文件（[ADR-033](../adr/033-skill-index.md)，格式见 [06-prd §6.13](../design/06-prd.md)）。

- **来源**：Notion「技能索引（Skill Index）」数据库，每行一条；`id` 用 Notion 页面 id，所以在 Notion 里改名不会变成新技能。
- **导入**：应用 →「技能」→「导入技能索引…」→ 选这个文件。文字以文件为准，常用位与使用次数保留；文件里没有的技能会被删除（要保留历史请在 Notion 把状态改为「已退役」）。
- **更新**：在 Notion 改完后，让 Claude「从 Notion 重新生成技能索引文件」，再导入一次。
- **校验**：`cargo test` 里的 `the_shipped_skill_index_imports` 会导入这份文件，并要求每个主动叫、已装的技能都有阶段和调用句。
