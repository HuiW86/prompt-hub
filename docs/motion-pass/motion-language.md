## 1. 对 design-spec §3.1 的增补（时长 token）

| Token | 值 | 用途 |
|-------|----|------|
| `--d-instant` | 0ms | **按下**（v0.30）：按下首帧即响应，松开走元素自己的 `--d-fast` 缓回——按下永远不迟 |
| `--d-loop` | 1200ms | **循环指示器**（v0.30，仅不确定进度条）：循环不是「变化」，不受 200ms 上限约束；减少动态效果时冻结 |

hard rule 改为：禁止 > 200ms 的动画（`--d-loop` 循环指示器除外）。

## 2. 新增 design-spec §3.4

### 3.4 动效语言（v0.30 — 2026-11 动效 pass）

同一类状态变化用同一套节奏；动效只回答「从哪来、到哪去、和什么有关」，不做装饰。只动合成属性（`transform` / `opacity`）与轻量绘制属性（颜色 / 边框色），不过渡 `width` / `height` / `top` / `left`（分段滑块的 `width` 例外：绝对定位的伪元素，不推挤任何兄弟）。

| 状态变化 | 节奏 | 动什么 | 落点 |
|---|---|---|---|
| 悬停 | `--d-fast` | 颜色 / 边框 / 透明度；管理区可交互卡叠 `--lift-1` | 全部可交互元素（网站、技能、位置菜单、状态栏此前缺失，已补） |
| 按下 | `--d-instant` 入、`--d-fast` 出 | 未填充控件 8% fill；填充控件去掉悬停阴影；悬浮卡回落 `translateY(0)` | primitives `Button` / `IconButton` / `Chip` / 行；Macro 卡、话术卡、最近使用、Modifier 芯片、场景色块 |
| 选中在兄弟间移动 | `--d-base` | 一块共享滑块 `transform` + `width` 滑到新位置（`useSegmentThumb` + `motion.module.css`）；首次落位与窗口 / 字号变化不动画 | Header 工作区、调用 / 整理、设置弹窗分段控件与左侧分页、Scene 标签 |
| 键盘选择 | 新选中 `--d-instant`，旧选中 `--d-fast` 淡出 | 底色 / 边框 | 全景（方向键会自动重复，缓入的高亮会拖尾） |
| 工作区 / 设置分页切换 | `--d-fast` | 新内容只淡入，不位移 | **仅用户亲手切换**；唤起回全景（C1）不动画 |
| 浮层出现 | 弹窗 `--d-base`；Toast `--d-slow`；锚定编辑器 / 悬停预览 `--d-fast` | `opacity` + 从锚点一侧 `--s-1` 漂入（锚定类）/ 2% 缩放（弹窗） | 设置、漂移账、Toast、锚定编辑器 / 位置菜单、悬停预览（仅冷启动） |
| 浮层离开 | `--d-fast`，比入场短 | `opacity`（弹窗加 2% 缩放、Toast 下沉 `--s-1`） | 设置弹窗、Toast；离开中的节点 `inert` / `pointer-events: none`，不挡下一次操作 |
| 刻意不做离开动画 | 立即 | — | 锚定编辑器 / 位置菜单（卸载即归还焦点，`[popover]` 唤起守卫依赖它）、搜索浮层（结果贴着打字走）、悬停预览的主动关闭与热切换 |
| 反馈 flash | `--d-fast` | `ph-flash`：首帧上色、前半程保持、后半程交还元素当前底色；同一目标连按会重播 | 全部复制入口，全景 / 技能也改走 `ph-flash` |
| 数值 / 进度 | `--d-base` | 用量条与下载进度条改 `scaleX`，不再跳 | 全景 / 技能用量条、更新下载条 |
| 加载循环 | `--d-loop` | 单向扫过 | 更新下载的不确定进度条（原 200ms 来回抖动） |
| 减少动态效果 | — | 全局 `tokens.css` §6 把时长压到 0.01ms；组件不再各写 `transition: none` | 全局 |

### 2026-11-25（三）— 动效 pass：一套动效语言

#### 变更内容

- **design-spec v0.29 → v0.30**：§3.1 新增 `--d-instant`（按下）/ `--d-loop`（循环指示器）；新增 §3.4 动效语言表；§10.11 悬停预览放行冷启动入场
- **共享件**：`src/styles/motion.module.css`（分段滑块、内容淡入）+ `src/hooks/useSegmentThumb.ts`
- **选中会滑动**：Header 工作区、调用 / 整理、设置弹窗分段控件与左侧分页、Scene 标签改为一块滑块滑到新位置
- **工作区切换**：用户亲手切换时新视图 `--d-fast` 淡入（唤起回全景不动画，C1）；技能 / 常用网站面板在指针移上标签时预加载，首次切换不再闪「加载中…」
- **有来有去**：Toast 加离开动画、连续出现只换文字不重新弹出；设置弹窗加离开动画（离开中 `inert`，焦点立即归还）；漂移账弹窗补入场；锚定编辑器 / 位置菜单从锚点一侧漂入；悬停预览冷启动淡入
- **反馈**：`ph-flash` 结束时交还底色而不是最后一帧突变；同一目标连按会重播；全景 / 技能的复制高亮改走 `ph-flash`
- **按下**：primitives 控件与悬浮卡补按下态（首帧响应、松开缓回，悬浮卡回落）
- **数值**：全景 / 技能用量条、更新下载条改 `scaleX` 过渡；不确定进度条由 200ms 来回抖动改为 1.2s 单向扫过
- **补齐**：网站、技能、位置菜单、状态栏、搜索图标、设置开关缺失的过渡；全景局部 `transition: none` 删去，统一交给 `tokens.css` §6
- **文案**：调用 / 整理提示改为「点击即复制，复制后自动隐藏窗口」/「窗口保持打开，可调整内容与位置」（原整理提示在全景下与实际行为不符）

#### 变更原因

HuiW86 2026-11-25 要求把整体动效做到「细腻、丝滑」的水准：按状态变化逐一检查，同类变化统一节奏，克制、可打断、不付性能代价，并尊重减少动态效果。方案、交互与文案顾问为 Gemini，合并前审查为 GPT（Codex）。

#### 实测（无界面 Chrome + 假 IPC，非真机 WKWebView）

- 1440×900 与 900×640，深浅色：布局偏移 0；帧间隔 p95 16.8ms
- 640 条全景条目压力测试（连点模式切换、悬停扫 60 行、方向键 30 次）：与 `main` 同脚本对比四轮，长帧数量与最大帧相当（均为切模式时整表重渲染，非本次引入）
- 减少动态效果下滑块与淡入时长为 0.01ms
