修复 macOS 27 上启动即闪退。

## 这个版本改了什么

**macOS 27 上不再启动两秒就退出。** 升级到 macOS 27 后，v0.2.0 一启动就崩溃，崩溃报告里是 `TaoWindow -> KeyablePanel isa-swizzle: instance size mismatch`（`536` 对 `528`）。

原因在让窗口「浮在所有应用之上、又不抢焦点」的那段 macOS 原生处理：它要把窗口换成一种面板类型，前提是两者在内存里的大小完全一致。旧版 macOS 上两者一样大只是巧合，macOS 27 调整了系统窗口的内部布局，巧合不再成立，安全检查直接中止了程序。

现在面板类型会按窗口的实际布局构建，在各个 macOS 版本上都对得上。万一哪天系统再变、对不上了，应用也不会闪退：窗口会退回普通的置顶窗口，照样能用，只是唤起时会抢焦点。

## 升级

在设置里开了更新检查的话，启动时会提示。也可以在设置里手动「检查更新」。发现新版本只提示，下载和安装仍然要你确认。

**已经升到 macOS 27、应用打不开的**：应用内更新走不到，请从本页下载 `.dmg` 手动安装覆盖。

数据不受影响——这个版本不动你的 SQLite 库。
