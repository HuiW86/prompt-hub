新增「常用网站」页，主界面减掉一批重复文字，复制提示不再挡住按钮。

## 这个版本改了什么

**常用网站。** 顶部「提示词」旁边多了「常用网站」页，可以分组收好常去的网址，点一下用默认浏览器打开。删掉的网站可以马上撤销，之后也能从页内的「已删除」里找回。网站和提示词分开存放，互不影响。

**主界面更清爽。**

- 区域标题后面的说明文字去掉了，只留区域名。
- 相位条每格只显示序号和名称。`⌘1`–`⌘9` 照常可用，鼠标停在格子上会提示对应的快捷键。
- 对齐话术那一行的标签改成中文「对齐」。
- 复制后的提示从右上角挪到底部居中，不再盖住「调用 / 整理」切换和设置按钮。
- Modifier 原子库的词块排列整齐了，不再每个后面空一块。
- 「最近使用」里的名称对成一列。
- Macro 卡片每一行都一样宽，最后一行不再被拉长。

## 升级

在设置里开了更新检查的话，启动时会提示。也可以在设置里手动「检查更新」。发现新版本只提示，下载和安装仍然要你确认。

## 数据

这个版本会给数据库加两张存网站的表（`user_version` 14 → 15）。改表之前会自动备份一份，原有的提示词和使用记录不动。

导出文件的格式版本从 1.3 升到 1.4，多了网站部分。旧版导出的文件照样能导入，不会清掉已有的网站。
