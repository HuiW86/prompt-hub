调用态的空间重新分配了一遍。

上一版把 Macro 区压在一个 200px 的固定高度里，13 张卡要滚动才看得全；而它下面的「最近使用」占着整列剩余空间，其中一大半是空白。一个按快捷键唤起、抓了就走的界面，最常用的区域反而需要滚动——这是反的。

## 这个版本改了什么

**Macro 区吃满热区。** 不再有固定高度上限，Macro 拿走整列剩余空间，一屏可见的卡片数量大约翻了一倍半。「最近使用」收成按内容高度钉在底部。

**「最近使用」按资产去重。** 连着复制同一个 Macro 五次，以前会占满整个列表五行——而"用了几次"这个信息 Macro 卡自己就写着。现在列表显示的是**五个不同的**资产，重复的只保留最近一次。

**滚动边界不再硬切。** 资产多到需要滚动时，底边改为渐隐，而不是把一张卡拦腰截断（旧的样子像渲染坏了）。

**SOP 进度收成一行。** 这块还是占位（功能仍在后续版本），但它原先占的空间是从上方正在使用的 Scene 那里拿的。顺带修好一个连带问题：Scene 里靠后的空子阶段，它们的「添加话术」按钮以前会被挤出可视区域。

**Modifier 底部托盘横排。** 象限分组改为并排，不再竖着堆占一条高带。

## 升级

在设置里开了更新检查的话，启动时会提示。也可以在设置里手动「检查更新」。发现新版本只提示，下载和安装仍然要你确认。

数据不受影响——升级不动你的 SQLite 库。

## 这个版本还没有

与 v0.1.0 相同：SOP 导航与录制仍是占位，相位固定八个不可编辑，没有副屏常驻形态，仅 macOS。

## 已知问题

话术卡在鼠标悬停时，右上角的操作按钮仍会盖住标题右侧。长标题在悬停时看不全，修复方向仍在讨论。

「最近使用」有一个边界情况：如果你连续大量复制同一个资产（多到刷满取数窗口），列表会显示得比五条少。复制一次别的资产即可恢复。
