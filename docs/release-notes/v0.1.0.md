prompt-hub 的第一个公开版本。

一个提示词资产的桌面仪表盘：按 **⌥Space** 唤起全屏窗口，找到要用的话术，复制走人。所有数据只存在你自己的机器上。

## 这个版本能做什么

**三层资产模型。** Modifier（原子方法论）/ Composition（组合）/ Macro（高频一键入口）——只有这三层，不再往下嵌套。Macro 区按使用频次排布，越常用的越好找。

**场景与子阶段。** 把话术按实际工作场景组织，场景内再分子阶段。话术可以跨场景、跨子阶段移动，移动后可撤销。

**协议层与任务层物理分离。** 相位（⌘1–⌘8）和对齐话术属于人机协议层，与任务层的资产互不混入。这是设计约束，不是布局选择。

**调用态与整理态。** 调用态下点一张卡就是复制，卡片只显示标题，正文不上屏——名字就是把手。整理态下点整卡是展开预览，复制变成显式动作，增删改都在这一侧。两态分开，取用和编辑不会互相误触。

**外观。** 深色 / 浅色 / 跟随系统，五路强调色，以及舒适 / 紧凑两档密度。紧凑档只收紧结构间距，字号和行高一律不动——密度不拿可读性换。

**数据导入导出。** 完整 JSON 导出，可搬到另一台机器。导入是整库替换，操作前会确认。

## 隐私

数据是一个本地 SQLite 文件，不上传到任何地方。这是设计前提，不是可配置项。

更新检查**默认关闭**，首次启动会问你一次。关着的时候零出站。开启后每次启动检查一次，请求只含当前版本号和芯片架构，不带任何话术内容或使用数据；发现新版本只提示，下载和安装都要你确认。随时可以在设置里关掉。

## 安装

按机器选对应的 `.dmg`：Apple Silicon 用 `aarch64-apple-darwin`，Intel 用 `x86_64-apple-darwin`。拖进 `Applications` 即可。安装包经过 Apple 签名与公证，正常双击就能打开。

完整说明见 [docs/install.md](https://github.com/HuiW86/prompt-hub/blob/main/docs/install.md)。

## 这个版本还没有

- **SOP 导航与录制**：界面上的「SOP 进度」目前是占位，功能在后续版本
- **相位自定义编辑、布局可配置**：相位目前是固定的八个
- **副屏常驻形态**：只有快捷键唤起的主形态
- **Windows / Linux**：仅 macOS

## 已知问题

话术卡在鼠标悬停时，右上角的操作按钮会盖住标题右侧。由于调用态下标题是卡片的唯一信息，长标题在悬停时会看不全。修复方向正在讨论中。
